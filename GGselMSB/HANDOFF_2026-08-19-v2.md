                  source_price, is_top, ...)
               VALUES (?, ?, ?, ?, ?, ?, ?, 1, ?, ?, ?, datetime('now'), ...)

                  price=excluded.price, my_price=excluded.my_price,

## ⚠️ Gotchas (пополнено к v1)

### Из v1 (повторить если не помнишь)
- `seller_categories.id` и `category_slug_mapping.seller_id` = `ggsel_digi_catalog`, **НЕ** live seller API id. Поле названо `seller_id` — это витрина.
- Корневой fallback "Другое" = **33833** (live seller API), не `121712`.
- MSB профиль 95 visible mode: `playwright.chromium.connect_over_cdp("http://127.0.0.1:PORT")`. `cdpPort` динамический.
- `fetch` через `page.evaluate` с `credentials:'include'` — обязательно, иначе 401.
- BATCH=3 параллельных + 0.4s sleep — иначе 429.
- **PowerShell heredoc ломает кавычки** — Python-скрипты пиши через `write` tool, потом `python script.py`. НЕ `python -c "..."`.
- `remove-item` заблокирован — никаких удалений, мусор копится в корне.

### Новые (v2)
- **`cat_fees.json` ключи — строки**: `get_commission(33833)` работает, потому что делает `str(33833)`. Если кто-то поменяет на int ключи — сломается. В `tools/refresh_cat_fees.py` сохранение идёт через `json.dump`, который делает str-ключи автоматически. **НЕ менять формат cat_fees.json**.
- **`parsed_products.category_id` — INTEGER, не slug**. Парсер пишет число, UI может показать через JOIN с `seller_categories` по `seller_categories.id = parsed_products.category_id` (но учти — это `ggsel_digi_catalog`, для UI иерархии).
- **Flask нужно перезапускать** после edit `competitor_scanner.py` — он кеширует модули.
- **Тонкий момент pricing**: `calculate_my_price(price, int)` — если `int` не в `cat_fees.json`, вернётся DEFAULT_FEE=0.15. Чтобы избежать: всегда резолвить через `category_resolver.find_seller_category_id()` (он использует 4-уровневый fallback вплоть до `seller_categories.ggsel_digi_catalog`, который у нас есть в БД).
