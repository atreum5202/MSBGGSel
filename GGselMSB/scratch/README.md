# GGSeller — Scratch: регистрация на ggsel.net

## Что это

CLI-инструмент для массовой регистрации аккаунтов на ggsel.net
через профили MSB (MyStealthBrowser) с Outlook-почтами.

## Структура

```
scratch/
├── ggsel_register.js     # flow регистрации одного профиля (CDP + Playwright)
├── run_all_profiles.js   # runner: берёт профили из MSB, запускает последовательно
├── results.jsonl         # лог результатов (создаётся автоматически)
├── groups.json           # архив (больше не используется — источник правды MSB)
└── lib/
    ├── msb_client.js     # клиент MSB API
    └── results_store.js  # чтение/запись results.jsonl
```

## Требования

- Node.js 18+
- MSB (MyStealthBrowser) запущен на `http://127.0.0.1:17248`
- Профили в MSB имеют группу `"GGSeller"` и привязанные Outlook-почты
- В профиле MSB открыт Outlook (залогинен) — код из письма читается оттуда

## Быстрый старт

```bash
cd scratch
npm install

# Запустить регистрацию по всем профилям группы GGSeller
npm run register

# Или с параметрами
node run_all_profiles.js --group GGSeller --delay 15
```

## Параметры run_all_profiles.js

| Параметр  | По умолчанию | Описание                           |
|-----------|--------------|------------------------------------|
| `--group` | `GGSeller`   | Имя группы профилей в MSB          |
| `--delay` | `10`         | Пауза в секундах между профилями   |
| `action`  | `full`       | Действие: `full` / `login` / `code` |

## Остановка

- **Ctrl+C** — мягкая (дожидается конца текущего профиля)
- **Ctrl+C x2** — жёсткая (убивает немедленно)

## Результаты

Каждый запуск дописывает в `results.jsonl`. Формат:
```json
{"profileId":"...","email":"...","status":"success","registeredAt":"..."}
```

Статусы: `success` / `error` / `skipped` (уже зарегистрирован ранее)

Просмотр результатов в консоли:
```bash
npm run results
```

## Источник профилей

Профили берутся из MSB API (`GET /profiles`), фильтруются по полю `group`.
`groups.json` — архивный файл, больше не используется.

## Поддерживаемые типы аккаунтов

| Тип почты            | Поддержка | Примечание                                        |
|----------------------|-----------|---------------------------------------------------|
| **Outlook / Live**   | ✅ Работает | Полный флоу — код приходит в outlook.live.com   |
| **Gmail**            | ❌ Пропускается | Не реализовано, профили игнорируются автоматически |

## Известные проблемы

### 403 от Qrator после перезапуска профиля
**Причина:** Qrator-куки сбрасываются при каждом перезапуске браузера.  
**Решение:** Прогреть профиль через MSB Warmer перед запуском флоу:
```bash
curl -X POST http://127.0.0.1:17248/api/warmer/start \
  -H "Content-Type: application/json" \
  -d "{\"profileIds\":[\"<PROFILE_ID>\"]}"
```
Ждать `hasQrator: true` в статусе, затем запускать флоу.

### Профиль закрылся во время флоу
**Причина:** MSB не запущен или профиль не стартовал.  
**Решение:** Убедиться что MSB работает на `:17248`, затем повторить.
